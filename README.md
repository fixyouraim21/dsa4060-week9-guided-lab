# DSA4060 Week 9 Guided Lab

## Topic
Implicit Feedback and Machine Learning using Confidence-Weighted ALS.

## Description
This project demonstrates how implicit user interactions can be used to generate ranked recommendations using Alternating Least Squares (ALS).

## Technologies Used
- Python
- Pandas
- NumPy
- SciPy
- Implicit ALS

## Contents
- Event log generation
- Interaction strength calculation
- Preference and confidence weighting
- Sparse user-item matrix
- ALS model training
- Top-5 recommendations
- Model experimentation and evaluation
